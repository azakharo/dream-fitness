# date_time_rules.md

Для вычислений даты или времени используй date-fns npm package.

## Guidelines

- Используй date-fns для арифметических операций с датой или временем.
- Используй date-fns для форматирования даты или времени.
- Используй date-fns для вычисления продолжительности (period, interval).
