# План реализации темы DreamFitness

## 1. Принятые решения

### 1.1. Направление дизайна

**Энергичный и динамичный** — яркие зелёные градиенты, насыщенные цвета, ощущение энергии и движения.

**Референсы:**

- Fitbit — яркие, насыщенные цвета
- Spotify (лаймовый бренд) — энергичный молодёжный стиль
- MyFitnessPal — динамичный спортивный интерфейс

### 1.2. Цветовая палитра

**Lime** — жёлто-зелёный, энергичный и молодёжный оттенок.

| Переменная    | Значение OKLCH         | Назначение                         |
| ------------- | ---------------------- | ---------------------------------- |
| Primary       | `oklch(0.68 0.22 130)` | Основной цвет кнопок, ссылок       |
| Primary Light | `oklch(0.85 0.18 130)` | Hover состояния, светлые акценты   |
| Primary Dark  | `oklch(0.50 0.18 130)` | Active состояния, текст на светлом |
| Accent BG     | `oklch(0.94 0.10 130)` | Фон для карточек, бейджей          |

## 2. Структура темы

### 2.1. CSS переменные для обновления

Файл: [`frontend/src/index.css`](frontend/src/index.css)

```css
:root {
  /* Primary — Lime */
  --primary: oklch(0.68 0.22 130);
  --primary-foreground: oklch(0.98 0.01 130);

  /* Secondary — нейтральный серый */
  --secondary: oklch(0.96 0.01 130);
  --secondary-foreground: oklch(0.3 0.02 130);

  /* Accent — светлый lime для фонов */
  --accent: oklch(0.94 0.1 130);
  --accent-foreground: oklch(0.35 0.12 130);

  /* Muted — приглушённый фон */
  --muted: oklch(0.96 0.01 130);
  --muted-foreground: oklch(0.5 0.02 130);

  /* Ring — цвет фокуса */
  --ring: oklch(0.68 0.22 130);

  /* Chart colors — градиент от lime к изумрудному */
  --chart-1: oklch(0.68 0.22 130);
  --chart-2: oklch(0.6 0.2 140);
  --chart-3: oklch(0.55 0.18 150);
  --chart-4: oklch(0.5 0.16 155);
  --chart-5: oklch(0.45 0.14 160);

  /* Sidebar — для админ-панели */
  --sidebar-primary: oklch(0.68 0.22 130);
  --sidebar-accent: oklch(0.94 0.1 130);
}
```

### 2.2. Дополнительные семантические цвета

Для энергичного стиля добавим:

```css
:root {
  /* Success — зелёный для успешных действий */
  --success: oklch(0.72 0.19 142);
  --success-foreground: oklch(0.98 0.01 142);

  /* Warning — жёлто-оранжевый */
  --warning: oklch(0.8 0.16 85);
  --warning-foreground: oklch(0.3 0.08 85);
}
```

## 3. Визуальные эффекты

### 3.1. Градиенты

Для энергичного стиля используем градиенты:

```css
/* Градиент для hero-секций и карточек */
.gradient-primary {
  background: linear-gradient(
    135deg,
    oklch(0.75 0.22 125),
    oklch(0.65 0.2 135)
  );
}

/* Градиент для кнопок при hover */
.gradient-button-hover {
  background: linear-gradient(135deg, oklch(0.7 0.24 128), oklch(0.6 0.22 138));
}
```

### 3.2. Тени с цветным оттенком

```css
/* Тень кнопки с lime-оттенком */
.shadow-primary {
  box-shadow: 0 4px 14px oklch(0.68 0.22 130 / 0.35);
}
```

## 4. Типографика

Текущий шрифт: **Geist Variable** — современный, читаемый.

Дополнительные рекомендации:

- Заголовки: `font-weight: 600-700`
- Основной текст: `font-weight: 400`
- Акцентный текст: `color: var(--primary)` для выделения

## 5. Компоненты shadcn/ui

### 5.1. Текущий стиль

- **Style:** `radix-nova`
- **Base Color:** `neutral`

### 5.2. Рекомендуемые действия

Обновить тему можно двумя способами:

**Вариант A: Ручное обновление CSS**

- Отредактировать [`frontend/src/index.css`](frontend/src/index.css)
- Заменить нейтральные цвета на lime

**Вариант B: Использовать shadcn CLI**

```bash
npx shadcn@latest init --preset lime --force --no-reinstall
```

Рекомендуется **Вариант A** — более контролируемый подход.

## 6. План действий

### Шаг 1: Обновить CSS переменные

- Файл: [`frontend/src/index.css`](frontend/src/index.css)
- Заменить `--primary` и связанные цвета на lime-палитру

### Шаг 2: Добавить семантические цвета

- Добавить `--success`, `--warning` переменные
- Зарегистрировать их в `@theme inline`

### Шаг 3: Создать CSS утилиты для градиентов

- Добавить gradient-классы для повторного использования

### Шаг 4: Обновить документацию

- Добавить секцию о теме в [`doc/Frontend-ADR.md`](doc/Frontend-ADR.md)

### Шаг 5: Удалить временные файлы

- Удалить [`frontend/theme-preview.html`](frontend/theme-preview.html)
